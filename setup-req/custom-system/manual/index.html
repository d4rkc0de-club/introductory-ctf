This is not Linux.
Do not assume that familiar operating-system concepts exist here.

01 — THE WORLD

The system contains entities. Entities have an identity, a state, and relationships to other entities.

They are not files and the identifiers are not paths.

02 — OBSERVATION

Observation does not change system state. If an entity tells you that something is required, treat that statement as part of the system's rules.

03 — STATE

Entities can be dormant, active, or sealed. State-changing operations may have prerequisites.

04 — RELATIONSHIPS

An entity may contain links to other entities. Following links is more useful than guessing names.

05 — DATA

Some entities contain data in a representation that is not immediately human-readable. Identify the representation before trying to interpret it.
